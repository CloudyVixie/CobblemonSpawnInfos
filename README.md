# ☁️ Sobre

O CobblemonSpawnInfos organiza dados de spawn do Cobblemon em arquivos JSON.

O projeto nasceu de uma necessidade simples: consultar essas informações de forma mais rápida.

Cada espécie fica em um arquivo separado, seguindo o número da Pokédex.

O projeto também serve como prática de Python, arquivos e dados estruturados.

# 📦 Dados

Cada Pokémon possui um arquivo com este padrão:

```text
0001_bulbasaur.json
0002_ivysaur.json
0003_venusaur.json
```

Os arquivos podem guardar dados como:

- Pokémon
- Tipo de spawn
- Peso
- Nível
- Condições
- Biomas
- Regras de aparição

---

# 📂 Estrutura

```text
CobblemonSpawnInfos/
├── 0001_bulbasaur.json
├── 0002_ivysaur.json
├── 0003_venusaur.json
├── ...
├── 1001_wochien.json
├── LICENSE
└── README.md
```

A divisão por espécie facilita a consulta e o uso dos dados em outros scripts.
