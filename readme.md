☁️ Sobre

O CobblemonSpawnInfos foi meu primeiro projeto que começou a ir além de exercícios pequenos.

A ideia surgiu da necessidade de consultar informações de spawn do Cobblemon de uma forma mais organizada, transformando os dados das espécies em arquivos JSON separados e fáceis de consultar.

Além da utilidade no jogo, o projeto serviu como uma forma de colocar em prática conceitos de Python, manipulação de arquivos e estruturas de dados.

⸻

📦 Dados

Cada Pokémon possui seu próprio arquivo seguindo o padrão:

0001_bulbasaur.json
0002_ivysaur.json
0003_venusaur.json
...

A numeração facilita a localização das espécies e mantém os arquivos organizados de acordo com a Pokédex.

Os dados armazenados incluem informações relacionadas às condições de spawn, como:

* Pokémon
* tipo de spawn
* peso
* nível
* condições
* biomas
* outras regras de aparição

⸻

📂 Estrutura

CobblemonSpawnInfos/
│
├── 0001_bulbasaur.json
├── 0002_ivysaur.json
├── 0003_venusaur.json
├── ...
├── 1001_wochien.json
│
└── README.md

A estrutura foi pensada para permitir que cada espécie seja consultada ou processada individualmente.

🎯 Objetivo

O projeto tem dois propósitos principais:

Uso pessoal

Facilitar a consulta das condições necessárias para encontrar determinados Pokémon no Cobblemon.

Prática

Aplicar conhecimentos de Python em um projeto que trabalha com uma quantidade grande de dados estruturados.
